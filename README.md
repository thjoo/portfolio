# Portfolio

Persönliches Portfolio mit Three.js.

## Entwicklung

```bash
npm install
npm run dev      # http://localhost:5180
npm run cities   # src/data/cities.json neu erzeugen
```

## Datenquellen

- Landflächen: [Natural Earth](https://www.naturalearthdata.com/) via `world-atlas` (Public Domain)
- Städte für die Stadtlichter: [GeoNames](https://www.geonames.org/) via `all-the-cities` (CC BY 4.0)
